精度と時間のバランス（既定の段階）

アップロード画面で段階を選ばなかったときに使う段階です。変更は次のジョブから有効です（処理中・待機中のジョブには影響しません）。利用者はアップロードのたびに段階を変えられます。

段階3 がこれまでの KoeLog と同じ設定です。
{% for m in quality_models %} {% endfor %}
段階 名前 モデル 1時間の会議 時間の根拠 メモリ目安 モデルの取得
{{ m.level }} {{ m.name }} {{ m.model_size }} およそ{{ m.hour_minutes }}分 {% if m.learned %} {{ m.time_basis }} {% elif m.ratio_measured %} {{ m.time_basis }}（実績{{ m.samples }}本） {% else %} {{ m.time_basis }} {% endif %} 約{{ m.model_mem_mb }}MB {% if m.downloaded %} 取得済み {% else %} 未取得（初回に約{{ m.download_gb }}GBのダウンロード） {% endif %}

「未取得」の段階を初めて使うときは、文字起こしの前にモデルのダウンロードが走ります（回線によって数分〜数十分）。ダウンロード中はジョブ一覧に「モデル準備中」と表示され、失敗した場合はジョブが失敗として記録されます。既定の段階を変えると、次回の起動時にもそのモデルの読み込みが走ります（読み込みは裏で行うため、画面自体はすぐ開きます）。

「1時間の会議」の数字のうち「未実測の見込み」と書いてあるものは、検証用PCの実測から換算した見込みで、このサーバーで測ったものではありません。実際のジョブが2本たまると、このサーバーの実績に自動で切り替わります。また精度の比較に使った正解データは「文字起こしの出力に人が修正を入れたもの」で、独立した正解ではありません。落ちた発話は正解側にも載っていないため、実際の取りこぼしはここに出る数字より多い可能性があります。
